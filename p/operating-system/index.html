第一章 引论

操作系统的主要功能

功能内容
处理机管理进程/线程调度、分配 CPU
存储器管理内存分配、虚拟存储、地址映射
设备管理I/O 分配、缓冲、驱动
文件管理文件存取、目录、权限
用户接口命令行、图形界面等（原文「窗口管理」多指用户接口层）

操作系统在计算机系统中处于硬件与用户/应用程序之间，是对硬件资源的抽象与管理者。

操作系统的特征

特征含义
并发两个或多个事件在同一时间间隔内发生（宏观同时、微观交替）
共享资源可供多个并发进程共同使用（互斥共享 / 同时访问）
虚拟把一个物理实体变为多个逻辑对应物（虚拟 CPU、虚拟内存等）
异步进程以不可预知的速度推进，需同步机制协调

操作系统的基本类型

类型特点
批处理多道程序并发，提高资源利用率，少交互
分时时间片轮转，用户可交互，响应及时
实时优先处理紧急事件，强调实时性与可靠性

第二章 进程的描述与控制

进程的概念

  • 定义：程序的一次动态执行过程（程序是静态的）。
  • 组成：PCB（进程控制块）+ 程序段（代码）+ 数据段（运行数据）。

进程的特征

动态性、并发性、独立性、异步性、结构性（由 PCB 描述）。

三级调度

调度作用
高级（作业）调度从外存后备队列选作业进入内存，建立进程，送入就绪队列
中级调度挂起/唤醒：内存紧张时把暂不运行进程换出；宽松时再换入
低级（进程）调度从就绪队列选进程，分配 CPU，进入运行态

进程状态转换

转换典型原因
运行 → 就绪时间片用完；被更高优先级进程抢占
运行 → 阻塞等待 I/O、等待资源、等待某事件发生
阻塞 → 就绪等待的事件发生（I/O 完成等）
就绪 → 运行被调度程序选中

进程通信（IPC）

方式说明
共享存储映射同一块内存区域
消息传递消息头 + 消息体，send/receive
管道半双工/全双工字节流（匿名管道、命名管道）

线程

对比进程线程
定位资源分配基本单位调度/执行基本单位
并发进程间可并发进程内线程也可并发
控制块PCBTCB（含线程 ID）
状态就绪、运行、阻塞同样三种基本状态

实现级别

类型说明
用户级线程线程库在用户空间调度，内核无感知
内核级线程内核参与调度；常见 1:1（一用户线程对应一内核线程）

第三章 处理机调度与死锁

调度方式

方式说明
非抢占进程占用 CPU 直到结束或主动放弃
抢占有更重要/更紧迫进程时，剥夺当前 CPU

调度评价指标

指标公式 / 含义
周转时间完成时间 − 到达时间
带权周转时间周转时间 ÷ 服务时间
等待时间周转时间 − 服务时间（或 在就绪队列中等待之和）
响应时间提交到首次响应（分时系统重要）
响应比（等待时间 + 服务时间）÷ 服务时间
CPU 利用率CPU 忙碌时间 ÷ 总时间
系统吞吐量完成作业数 ÷ 总时间

调度算法

1. 先来先服务（FCFS）

按到达顺序，非抢占。实现简单，短作业等待长作业时平均周转时间可能较大。

2. 短作业优先（SJF）

优先服务时间短的进程。

类型规则
非抢占 SJF当前进程运行完，在已到达进程中选服务时间最短
抢占 SJF（SRTN）新进程到达时，若其服务时间更短则抢占

3. 优先级调度

按优先级高者优先；同优先级可按 FCFS。分抢占 / 非抢占。

4. 高响应比优先（HRRN）

非抢占，每次选择响应比最高的进程。

5. 时间片轮转（RR）

就绪队列 FCFS，每进程运行一个时间片，用完排到队尾。

优点缺点
公平、响应快，适合分时时间片难选；不区分紧急程度；上下文切换开销

6. 多级反馈队列（MLFQ）

  • 多级队列，优先级从高到低，时间片从小到大
  • 新进程进入最高级队列，FCFS + RR
  • 时间片用完未结束 → 降到下一级队尾
  • 已在最低级则仍在最低级队尾轮转

死锁

各进程互相等待对方持有的资源，导致都无法推进。

产生必要条件（四者同时成立）

  1. 互斥：资源只能互斥使用
  2. 占有并等待：持有资源的同时等待其他资源
  3. 不可剥夺：资源只能由持有者主动释放
  4. 循环等待：存在进程资源的环形等待链

处理策略

策略思路
预防破坏四条件之一（如按序分配资源）
避免分配前判断是否进入不安全状态（银行家算法）
检测允许发生，定期检测并恢复
解除剥夺资源、回滚、杀死进程等

安全状态 → 一定不会死锁；不安全状态 → 可能死锁。

银行家算法（避免死锁）

矩阵含义
Available可用资源向量
Max各进程最大需求
Allocation已分配
Need还需资源，Need = Max − Allocation

安全序列：若存在一种分配顺序使所有进程都能完成，则当前为安全状态。

死锁检测（资源分配图）

  • 方框：资源类；圆：进程
  • 资源 → 进程：已分配；进程 → 资源：正在请求
  • 资源耗尽 + 循环等待 是死锁关键特征

第四章 进程同步

基本概念

概念说明
进程同步多进程按一定次序协作，保证可再现性
进程互斥访问临界资源时排他，同一时刻仅一进程进入临界区
临界资源一次仅允许一个进程使用的资源（打印机、共享变量等）

信号量机制

原语别名含义
wait(S)P申请资源，S--；若 S<0 则阻塞
signal(S)V释放资源，S++；若 S≤0 则唤醒等待者
用途初值用法
互斥S = 1进入临界区 P，离开 V
同步S = 0前驱操作后 V，后继操作前 P

经典问题

生产者—消费者

角色操作语义
生产者P(空缓冲区)；生产；V(满缓冲区/产品)
消费者P(产品)；消费；V(空缓冲区)

常用信号量：mutex=1（互斥访问缓冲区）、empty=n、full=0。

读者—写者

  • 多个读者可同时读
  • 写者互斥，且读写互斥
  • 用 readcount + mutex 保护计数；写者用 rw_mutex

第五章 存储器管理

目标

解决「程序逻辑地址空间 > 物理内存」：覆盖、交换、分页、分段、段页式。

连续分配

1. 单一连续分配

系统区（低地址）+ 用户区（用户进程）。简单，无碎片，利用率低。

2. 固定分区

内存划分为固定大小分区，每区一道作业。有内部碎片。

3. 动态分区

按进程需要动态划分，有外部碎片，需紧凑。

动态分区分配算法

算法策略
首次适应 FF从头找第一个足够大的空闲区
最佳适应 BF选最小且够用的空闲区（易留小碎片）
最坏适应 WF选最大空闲区
邻近适应 NF从上次查找结束位置继续（首次适应的改进）

分页存储管理

逻辑地址 → 页号 + 页内偏移；物理地址 → 块号 + 块内偏移。

1
2
3

页号   = 逻辑地址 / 页面长度（整除）
页内偏移 = 逻辑地址 % 页面长度
物理地址 = 页表[页号].块号 × 页大小 + 页内偏移

概念说明
页表页号 → 块号映射
TLB快表，加速地址变换
多级页表节省页表连续空间

第六章 虚拟存储器

在分页基础上，只把当前需要的页调入内存，其余在辅存；缺页时页面置换。

页面置换算法

算法规则特点
OPT淘汰未来最久不再访问的页理论最优，无法实现
FIFO淘汰最先进入内存的页简单，可能 Belady 异常
LRU淘汰最近最久未使用的页性能好，实现成本高
Clock环形队列 + 访问位LRU 近似，常用

原文「最近醉酒」为 LRU（Least Recently Used） 之笔误。
OPT 中「置换次数」= 发生缺页且需换出的次数（内存已满后的换页）。

工作集与抖动

  • 抖动（颠簸）：频繁缺页，换页时间 > 执行时间
  • 缓解：增加物理块、局部置换、工作集算法

第七章 输入输出系统

磁盘调度（减少寻道时间）

假设当前磁头位置已知，请求队列给定。

算法规则
FCFS按请求到达顺序服务
SSTF每次选距磁头最近的柱面（可能饥饿）
SCAN（电梯）单向扫描到端点再反向；端点内只朝一个方向服务
C-SCAN循环扫描，只朝一个方向处理请求，到端点快速返回起点

原文「按照要地址的顺序」多指 FCFS；「莫个方向」为 某个方向（C-SCAN）。

I/O 控制方式（补充）

方式说明
程序直接控制CPU 轮询
中断驱动I/O 完成中断通知
DMA块设备与内存直接传，少占 CPU
通道专用 I/O 处理器
